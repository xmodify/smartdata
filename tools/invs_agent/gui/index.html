การตั้งเวลาส่งอัตโนมัติ (Schedule Timer)
ส่งทุกวันเวลา:
กฎการดึงข้อมูลอัตโนมัติ (รอบตี 1):
  • แฟ้ม INVENTORY: ดึงยอดคงคลังสะสม ณ วันก่อนหน้า (เมื่อวานเต็มวัน) โดยอัตโนมัติ เพื่อให้ได้ยอดเต็มวัน
  • แฟ้ม DRUGLIST, RECEIPT, DISTRIBUTION, PURCHASEPLAN: ดึงตาม ปีและเดือนปัจจุบัน โดยอัตโนมัติ
สั่งรันแบบเงียบ (Silent / Task Scheduler): สามารถตั้งใน Windows Task Scheduler ให้เรียก invs_agent.exe -s เพื่อให้แอบดึงและยิงข้อมูลอัตโนมัติในพื้นหลังโดยไม่เปิดหน้าต่าง
รันเบื้องหลัง เมื่อกดปิดหน้าต่าง [X] โปรแกรมจะยังคงรันอยู่เบื้องหลังที่ถาดไอคอนด้านล่างขวา (System Tray)
หากต้องการปิดโปรแกรม ให้คลิกขวาที่ไอคอนล่างขวาแล้วเลือก "ออกจากโปรแกรม (Exit)"
